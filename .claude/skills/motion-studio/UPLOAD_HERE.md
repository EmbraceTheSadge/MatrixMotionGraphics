# Upload the motion-studio skill here

This folder is the destination for the `motion-studio` skill
(the folder whose `SKILL.md` starts with `name: motion-studio`).

Place the **complete** folder contents directly in this directory so that
these paths exist:

```
.claude/skills/motion-studio/SKILL.md
.claude/skills/motion-studio/references/...
.claude/skills/motion-studio/scripts/setup.sh
.claude/skills/motion-studio/scripts/selftest.sh
.claude/skills/motion-studio/templates/...
.claude/skills/motion-studio/examples/...
```

Do not nest it as `.claude/skills/motion-studio/motion-studio-skill/SKILL.md`.
Do not include `node_modules/`, browser caches or model files.

You can delete this file once the skill is in place.
